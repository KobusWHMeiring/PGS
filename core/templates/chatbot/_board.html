It sits *below* the composer: the page is called *ask*, so a visitor with a question in their head must not scroll past the library to find the box. No logic lives here beyond `{% if %}`: counts, topics and cards arrive from `core.services._ask.board_context`, and the one-line summary is a model property. A card is a link only when `card.slug` exists, which is exactly when an administrator published it. The waiting copy is deliberately warm, never an error (DESIGN §7.9): a gap in what we publish is the product being honest, not the product being broken. {% endcomment %}
