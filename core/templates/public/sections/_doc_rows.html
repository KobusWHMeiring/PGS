{% comment %} The document list, with the seven-plus-one shape the live /forms/ page has: the four governed documents, the visit preparation list, and three blank participant checklists, plus one gated row for historical records. **Why "Publishing soon" rather than a Download button (P7, DESIGN rule 8):** `/documents/` is task C2 and does not exist yet. A link to it would raise `NoReverseMatch` at render time, and a plausible-looking `href="#"` would be a button that does nothing — which is the failure DESIGN rule 8 exists to forbid ("unresolved data is a tinted chip, never a plausible-looking fake"). C2 replaces these chips with real links to real files in one commit. The gated row is the exception and is already honest: dossiers are never public (D22), so its action is `Request access`, never `Download`. {% endcomment %}
